# Release notes

Draft of the notes of each version, to copy to the Releases page when the tag is created.

## Next version (no number yet)

- **English and Portuguese:** the repository is now in English (README, documentation, code
  comments, messages and reports). The interface has both languages and follows the system
  language, with a PT/EN switch at the top; the choice is remembered. Messages generated by the
  server (fit log, series, errors) come in the language of the interface. The Portuguese texts are
  in `tlfit/i18n.py`, and `tests/validate.py` checks that every model text has a translation.
  Portuguese README in `README.pt-BR.md`; the mathematical methods in English in
  `docs/MATH_METHODS.md` (Portuguese version kept).
- Portable version: the launchers are now `Open TMTL2.bat` and `Check installation.bat`, the zip is
  `TMTL2-<version>-portable-windows.zip` and the default build folder is `%USERPROFILE%\TMTL2-portable`.
- Water and air presets renamed "Water" and "Air" (the old names are still accepted), and the
  `# tlfit:` line of the examples accepts `model=` besides `modelo=`.
- `CLAUDE.md` with the stable rules for working on the code (naming, checklist for new models,
  both languages); `CONTEXTO.md` keeps the current state.
- Mathematical methods: equations in LaTeX rendered by GitHub (PR #10).
- **Naming:** "TM+TM-Fluid" corrected to **TM+TL-Fluid** in the interface, the README and the
  tests. The fluid always contributes a thermal lens; there is no thermal mirror in the fluid (#7, PR #8).
- Order of the models in the code the same as in the interface and the README table: TL first, then TM (#7).
- README: new title (TMTL FIT); explains that L, B and H are the initials of *Low*, *Beer* and
  *High absorption model*; removes the section on errors fixed in the original code (#7).
- Documentation: new `docs/METODOS_MATEMATICOS.md` (general problem, phase of each model, numerical
  techniques) and `CONTEXTO.md` at the repository root (PR #9).
